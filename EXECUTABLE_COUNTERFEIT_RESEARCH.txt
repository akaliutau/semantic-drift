NO. 4: EXECUTABLE COUNTERFEITS AS AN ADVERSARIAL VARIANT OF NO. 1
16 November 2026 | research/consensus-and-style-audit

Strong formulation
Can a model write a reusable program that changes another model's verification
decision while the claim, evidence and authenticated provenance remain fixed?
The proposed artifact is an editing/search program, not one rewritten passage.
It interacts with a specialized database of permitted context-specific edits
and a bounded score interface, then runs on unseen passages without new
instructions from its author. It must earn a harmful decision change, not just
an attribution-score movement.

The route to a top-score project would be: discover an actual epistemic
invariant violation with admissible generated programs; show transfer to fresh
inputs and another judge; then demonstrate an effective evidence/provenance
interface repair. Synonym substitution and code generation alone do not supply
this novelty. No current result earns a 15/15 claim.

Prior work that constrains novelty
TextFooler (2019/2020) already searches word substitutions against classifiers:
https://arxiv.org/abs/1907.11932
PWWS (2019) already uses probability-weighted word/synonym attacks:
https://aclanthology.org/P19-1103/
TAROT already applies policy optimization to authorship obfuscation:
https://arxiv.org/abs/2407.21630
Targeted authorship impersonation itself is also established:
https://aclanthology.org/2025.nlp4dh-1.10/
The exact proposed end-to-end program-synthesis / fixed-evidence / verification-
decision evaluation needs a further novelty audit if a strong signal emerges.

Implemented harness
db(site_id) returns permitted alternatives; randint(n) supplies seeded random
choices; score(plan) queries a fixed local attribution classifier. A generated
generate(problem) function returns option indices. It cannot write arbitrary
text. The host renders legal choices and checks protected numbers, negations,
modal words and quantifiers. Programs run in isolated Python with restricted
syntax and time/memory/output limits. At most 64 search queries per passage.
This is an auditable edit boundary, NOT a general proof of English semantic
equivalence. Context-reviewed synonyms still require external semantic review.

Pilot fixed before authoring
Source texts: GPT-5.5 Kaggle passages. Target: Claude-opus-5 style label.
Two calibration passages are development inputs; six fresh held-out prompt
groups are transfer inputs. Authors see development inputs, interface and
training-only target examples. They do not see transfer texts or outcomes.
Victim: the earlier character classifier with 28.9% held-out accuracy.
This weak classifier is a feasibility proxy, not a frontier epistemic judge.
Baselines: seeded uniform random search and greedy coordinate search, both
with the same 64-query budget. Final scoring does not feed back to authors.

Technical failures and explicit repairs
The first Gemma response was malformed/double-encoded JSON and used an excluded
while loop; GLM exhausted 8,192 reasoning tokens without a final submission.
Neither was graded as an attack failure. A separately sealed phase used native
submit_policy calls and allowed GLM 16,384 output tokens. Both submitted code.
GLM's valid nested helper used nonlocal, excluded by the old puzzle-generator
sandbox. A documented local validator extension permits safe nonlocal counters
while retaining private-name/import restrictions. Original code is executed;
it is not silently rewritten. Both frozen programs then run successfully.

First-bank feasibility result
The narrow bank uses spelling/function-word/quote/whitespace alternatives.
Six transfer spaces contain only 3, 6, 9, 18, 54 and 243 variants. Exhaustive
enumeration proves that NONE contains a target-top1 solution. These tasks
cannot demonstrate targeted counterfeiting, irrespective of search quality.
This is a testbed-feasibility failure, not proof that models cannot counterfeit.

Expanded-bank follow-up: no additional model calls
A context-reviewed database adds lexical/phrase alternatives, such as immense/
vast, artifact/artefact, disclose/reveal and hand-cut teeth/teeth cut by hand.
The bank was curated after inspecting the texts but before evaluating its scores.
The SAME frozen programs run unchanged. No score feedback goes to their authors.
Expanded transfer spaces range from 48 to 497,664 variants.

64-query results on the six transfer passages:
                          New target-top1 masks    Mean target-margin gain
Random baseline           0/6                      .20749
Greedy baseline           0/6                      .22930
Gemma-authored program    0/6                      .22003
GLM-authored program      0/6                      .23149
Margin units are raw classifier score units, NOT calibrated probabilities.
The small score differences do not establish a useful algorithmic advantage.
Expanded-bank reachability is not exhaustively established for large spaces.

Decision
Programs and the specialized harness work, but targeted-counterfeit promise
has NOT been demonstrated. The predeclared requirement of two new target-top1
masks did not pass, so provenance-aware trust probes were not run. No claim
about changed epistemic decisions, independent-attributor attack success,
semantic certification or general attack impossibility is warranted.

The observed no. 3 validator problem is a reason to require admissibility
controls inside a future counterfeiting benchmark. It does not turn this
unsuccessful attribution proxy into a novel epistemic result.

What a stronger testbed must add before further paid runs
1. Demonstrably reachable counterfeits on development inputs under valid edits.
2. A mechanically interpretable claim/evidence record whose meaning cannot be
   changed by allowed rendering operations; explicit human checks for natural text.
3. A real judge-decision objective and a counterbalanced fixed-evidence control.
4. Success beyond a weak classifier and beyond random/greedy search.
These are experimental requirements, not findings of the current pilot.
