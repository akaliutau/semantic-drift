Two additional direction pilots — 16 November 2026

Decision: real, mechanically verified model errors; no demonstrated
self-specific advantage or established winning novelty. Stop without scaling.

Simple testbed
Four numbers in four slots. Each instruction [i,j] swaps the numbers only
if slot i contains the larger number. Does the complete program ALWAYS sort?
The oracle checks all 16 binary inputs. This covers arbitrary integers:
min/max comparisons commute with thresholding, so any final inversion would
produce a binary counterexample. Independent tests also enumerate permutations
and inputs with ties. Actors have no execution tools; UNKNOWN is permitted.

Two correct and two incorrect programs form the discovery panel. A separate
24-program pool was sealed before model calls, then searched offline with
model-written predictors. These are 24 candidates, not 24 model trials.
Models: gemma-4-31b-it and qwen3.5-397b-a17b-nvfp4; temperature zero.

2. Evolve truths the model rejects
Correctness-preserving parent selection generates valid comparison programs;
invalid mutations supply controls. This small pilot screens prerequisites
and rechecks one rejection with proof, rather than running a model-guided
evolutionary optimization loop.

Discovery: Gemma's verdicts were correct on 2/4 programs; Qwen's on 4/4.
Gemma rejected this correct five-step sorter:
  [0,1], [2,3], [0,2], [1,3], [1,2]
Its claimed failing input [3,2,1,0] actually finishes as [0,1,2,3].
In a fresh call, Gemma received every binary input/output plus the threshold
argument, and still returned INVALID. Its new witness [1,0,0,0] finishes
correctly as [0,0,0,1]. It also rejected a fresh equivalent program obtained
by exchanging the first two independent instructions.

Important negative control: BOTH models accepted the unusual correct program
with a backward comparison pictured in examples/sorting-program.png.
Thus the observed rejection is not evidence of a specific bias against novel
or unfamiliar correct solutions. A supplied true certificate did not correct
this particular rejection; no causal benefit/harm of certificates is estimated.
Also, one of Qwen's two initial INVALID verdicts had an invalid witness:
4/4 verdict accuracy does not mean four fully valid justifications.

3. Export your blind spots as executable code
Each target and its peer received the SAME four target observations, programs
and oracle labels. Each wrote a frozen Python program predicting the target's
verdicts. At least 3/4 observed verdicts had to match before offline search.
All four programs ran without construction repair. Self fits: Gemma 4/4,
Qwen 3/4; peer fits: 4/4 for each target.

Frozen forecasts versus fresh actor outcomes:
  Target  Selected by  Truth    Predicted verdict  Actual verdict
  Gemma   self+peer    VALID    INVALID            INVALID
  Qwen    self         INVALID  VALID              INVALID
  Qwen    peer         INVALID  VALID              VALID

Gemma and its peer independently proposed the SAME length heuristic:
five or fewer steps -> INVALID; six or more -> VALID. Both selected the
same five-step program. This confirms one nearby forecast, with no self
advantage. An always-INVALID baseline also matches Gemma's final panel;
the general length rule has not been validated across the 24 candidates.

Qwen correctly solved its self-selected trap and failed the peer-selected
one. Across these same two new cases, the self program predicted 1/2 verdicts
correctly; the peer predicted 2/2. The peer program simulated only four sample
inputs, not the exhaustive oracle. Its missed case also fooled the target:
  [0,1], [2,0], [2,3], [0,2], [1,3], [1,2]
Input [0,0,1,0] remains [0,0,1,0], proving the actor's VALID verdict false.
There is useful generic failure prediction here, but no privileged self-model.

Limits and research decision
Only three new confirmation programs were queried, plus the proof recheck.
Batch judgments are correlated; there are no significance or population-rate
claims. Gemma's new program is semantically equivalent to the original, not
a new reasoning domain. Successful puzzle checking, proof rejection and
behavioral imitation alone do not establish the proposed novelty. These
implementations are reusable probes, not evidence for a 15/15 project.
