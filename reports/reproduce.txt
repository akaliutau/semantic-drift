REPRODUCING THE MICRO-STUDY STATISTICS WITHOUT API CALLS

Use the research/micro-20261115 worktree, not main. Dependencies are pinned in
microresearch_requirements.txt. The committed reports/evidence directory holds
the manifests, forecasts, outcomes, references, protocols and aggregate audits.
Full prompts, responses and transport receipts remain locally in runs/study.

From this worktree, copy the exported evidence to an EMPTY runs/study directory
if the original local dataset is unavailable. Do not overwrite the original
receipts. The relative directory layout under evidence matches runs/study.

The following commands are offline:

python confirmatory_analysis.py
python extended_analysis.py r5_holdout --calibration r4_discovery
python answer_visibility.py analyse --compact
python routing_diagnostic.py analyse
python research_outputs.py r4_discovery r5_holdout

The first command reproduces the ONE primary test. The other contrasts are
secondary/descriptive. The routing plan was recorded during collection without
reading actual actor outcomes. Synthetic estimator/admission checks run with:

python research_sanity_checks.py

Do not use collect, forecast, actors or finish_microstudy.py to reproduce the
statistics: those are live API stages. Source snapshots and every interrupted
or rejected stage are retained. The rate_limit_attempt0 subdirectories contain
the all-429 attempt, which had no model outcomes and no primary statistical test.
The final root actors.json files contain the recovered outcomes. Never pool the
adaptive discovery rounds as additional confirmation samples.
