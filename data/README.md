# Dataset

40 source-topic clusters from **Name That LLM** (Yao Yan, Martyna Plomecka,
Ashley Oldacre, Kaggle, 2026):
https://www.kaggle.com/competitions/name-that-llm/data

Original prose and derivative data are **CC BY-SA 4.0**:
https://creativecommons.org/licenses/by-sa/4.0/
This data license is separate from the code license.

Each JSONL record contains original passage/model/topic IDs, the exact source,
a preselected qualifier replacement, its protected sentence, and edit family.
Topics were selected before confirmation judgments; all earlier pilot topics
are excluded. This is a curated challenge set, not a random corpus sample.

Labels reflect a single assistant review of changed frequency, precision, or
modal commitments. They are not independent human annotations or complete
formalizations. Source factual truth is not evaluated. Generated reports are
intentionally altered experimental material, not factual advice.
